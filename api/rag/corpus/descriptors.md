# IELTS Writing Task 2 — Task Response (TR)
- Answer all parts of the prompt.
- Maintain a clear, explicit position throughout.
- Extend and support ideas with specific explanation and example in each body paragraph.

# IELTS Writing Task 2 — Coherence & Cohesion (CC)
- Organize with logical paragraphing and topic sentences.
- Use cohesion that attracts no attention (natural referencing/substitution, not excessive linkers).

# IELTS Writing Task 2 — Lexical Resource (LR)
- Use precise, appropriate lexis and collocations.
- Paraphrase accurately without distorting meaning; avoid repetition.

# IELTS Writing Task 2 — Grammatical Range & Accuracy (GR)
- Wide range of complex structures with high accuracy.
- Only rare slips; errors should not impede understanding.

# IELTS Writing Task 1 — Overview Requirement
- Provide a 1–2 sentence global overview without numbers.
- Capture main trends/extremes/stages, not details.

# IELTS Writing Task 1 — Key Features & Comparisons
- Select 3–5 salient features; avoid listing everything.
- Make valid comparisons with correct units/time; no speculation beyond given data.

# Invisible Cohesion (Good Practice)
- Prefer pronouns, substitution, and reference chains over heavy linking adverbs.
- Example: "This trend" instead of "Moreover, Furthermore, In addition" repeatedly.

# Time & Length Norms
- Task 1: ~20 minutes, ≥150 words.
- Task 2: ~40 minutes, ≥250 words; no bullets/notes.
